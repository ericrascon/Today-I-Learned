# Increase your Windows 11 productivity with Microsoft PowerToys

PowerToys is a new feature on Windoows 11 that allows the user to have more control over Windows 11 utilities and visuals. You can install PowerToys via the Microsfot Store, alot of these features need to turned on in the settings which are then utilized by shortcut keys.

Some 4 simple ones that were highlighted are:

1: Color Picker - use your mouse to hover over any image on the screen to get the HEX & RGB code, perfect for extracting the colors your client uses on deliverables for them!

2: ZoomIt tool - allows you to zoom in on specific areas while you're presenting on a screenshare along with annotating as well.

3: Find My Mouse - fairly straight forward and simple, double click on the `ctrl` key twice and you will get a visual to indicate where you mouse is on the screen.

4: Crop & Lock - personally my favorite one due to how innovative it is, you get to crop your windows in three 3 different formats. My preferred one, Reparent shortcut, allows you to crop a cetain portion of a screen and with that new crop window you are still able to click and interact with the functions despite it being cropped.

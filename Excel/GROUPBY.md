# GROUPBY Function

If you ever wanted to format a Data Table in a quick certain way without having to create a PivotTable, the GROUPBY formula is where it comes in handy.

The formula is as follows ` =GROUPBY(row_fields, values, function, [field_headers], [total_depth], [sort_order], [filter_array], [field_relationship])`. The two optional ones in that formula are the Field_headers and Total_depth.

It's important to note that this formula is only available in Microsoft Excel 365 and not Google Sheets.

## Examples
